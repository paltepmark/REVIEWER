Raster & Display Fundamentals

  • Raster: A 2D array of pixels displayed on screen.[span_3](start_span)[span_3](end_span)
  • Resolution: Total number of pixels in a raster.[span_4](start_span)[span_4](end_span)
  • Precision: Number of bits allocated per pixel.[span_5](start_span)[span_5](end_span)
  • Frame Rate: Image refresh frequency measured in Frames Per Second (FPS).[span_6](start_span)[span_6](end_span)

Framebuffer Memory Buffers

  • Color Buffer: Minimum required buffer; stores RGB color data.[span_7](start_span)[span_7](end_span)
  • Depth Buffer (Z-Buffer): Stores distance values to camera for visibility calculations.[span_8](start_span)[span_8](end_span)
  • Stencil Buffer: Used for advanced masking effects (shadows, reflections, portals).[span_9](start_span)[span_9](end_span)

4-Stage OpenGL Pipeline

1. Application

Executes primarily on the CPU. Handles user input, application state, and target loops (e.g., 60 FPS).[span_14](start_span)[span_14](end_span)

2. Geometry Processing

Executes on GPU via Vertex Shader. Handles vertex transformations, normal vectors, UV mapping, and space transforms.[span_15](start_span)[span_15](end_span)

3. Rasterization

Converts geometric primitives into discrete pixel fragments through Primitive Assembly.[span_16](start_span)[span_16](end_span)

4. Pixel Processing

Executes on GPU via Fragment Shader. Computes final per-pixel colors and applies z-buffer depth testing.[span_17](start_span)[span_17](end_span)
