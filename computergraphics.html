1. Major Areas & Core Definitions

Modeling

Mathematical specification of shape and appearance properties stored on a computer.

Rendering

Creation of shaded 2D raster images from 3D computer models.

Animation

Creating an illusion of motion via a rapid sequence of images (frames) measured in FPS.

Raster & Resolution

A 2D grid of pixels. Resolution = total pixels; Precision = bits used per pixel.

3. Framebuffer & GPU Architecture

Color Buffer

Minimum required buffer storing RGB color intensity values for each pixel.

Depth Buffer (Z-Buffer)

Stores distance values from scene objects to the camera to determine visibility and occlusion.

Stencil Buffer

Holds pixel values for generating special effects like shadows, reflections, and portal rendering.

APIs & Shader Languages

DirectX: HLSL (Microsoft)
Metal: Metal Shading Language (Apple)
OpenGL: GLSL (Cross-platform)

4. The 4 OpenGL Pipeline Stages

1. Application Stage (CPU)

Initializes window, reads assets, creates VBOs/VAOs, loads shaders, and passes uniform values.

2. Geometry Processing (GPU - Vertex Shader)

Applies transformations (Model → World, View → Camera, Projection → Clip Space) to transform 3D vertices.

3. Rasterization Stage (GPU)

Performs primitive assembly (points, lines, triangles) and identifies which pixels belong to the primitive, creating fragments.

4. Pixel Processing (GPU - Fragment Shader)

Computes the final color of each fragment using textures, uniforms, lights, and vertex colors.
