Module 1

Cloud Concepts Overview

1 Trade CapEx for OpEx

Replace upfront physical infrastructure investments (Capital Expenditure) with variable pay-as-you-go operating expenses (Operational Expenditure). Reduce unnecessary spending and scale according to demand.

2 Massive Economies of Scale

Aggregated usage from hundreds of thousands of customers allows providers like AWS to achieve higher economies of scale, passing savings directly to customers via lower pay-as-you-go prices.

3 Stop Guessing Capacity

Eliminate overprovisioning (unused idle equipment) and underprovisioning (capacity shortages/performance degradation) by dynamically scaling capacity up or down on demand.

4 Increase Speed & Agility

Provision IT resources in minutes via a few clicks or code instead of waiting weeks/months for hardware procurement, setup, and configuration.

5 Stop Spending Money on DC Ops

Outsource rack, stack, power, cooling, and hardware maintenance to the provider. Shift technical staff focus onto applications, business logic, and innovation.

6 Go Global in Minutes

Deploy applications across multiple AWS Regions worldwide effortlessly to reduce network latency and provide a superior customer experience globally.

Cloud Service Models

IaaS (Infrastructure as a Service)

Provides basic building blocks (virtual servers, storage, networking). Highest control over OS and software. Provider manages underlying hardware. (e.g., EC2)

PaaS (Platform as a Service)

Provider manages OS, hardware, database engines, and runtime. Developers focus exclusively on deploying and running code without maintaining infrastructure. (e.g., Elastic Beanstalk)

SaaS (Software as a Service)

Complete end-user applications delivered over the web. Managed entirely by the vendor. (e.g., Web-based email services)

Cloud Deployment Models

Cloud (Fully Cloud-based)

Applications are fully deployed in the cloud with all infrastructure running on cloud provider systems.

Hybrid

Connects cloud resources directly to legacy on-premises infrastructure to gradually migrate or keep sensitive on-prem systems integrated.

On-Premises / Private Cloud

Uses virtualization and resource management within company-owned data centers (resembles traditional IT).

Module 2

Cloud Economics and Billing

Fundamental Pricing Drivers

  • Compute: Charged by the hour or second depending on instance type/service.
  • Storage: Charged typically per gigabyte (GB) allocated/stored.
  • Data Transfer: Inbound data transfer is FREE. Outbound transfer is charged per GB across services.

Reserved Instance Options

  • All Upfront (AURI): Largest upfront payment, highest discount percentage.
  • Partial Upfront (PURI): Moderate upfront payment, medium discount.
  • No Upfront (NURI): $0 upfront payment, smallest discount among reserved options.
